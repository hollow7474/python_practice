# Консольный калькулятор

## Назначение
Консольное приложение на Python, которое выполняет арифметические операции над двумя числами.

## Какие задачи решает
- запрашивает два числа и операцию;
- выполняет: `+`, `-`, `*`, `/`, `//` (целочисленное деление), `%` (остаток), `^` (степень);
- обрабатывает ошибки: ввод не числа, неизвестная операция, деление на ноль.

## Новый функционал (практическая работа 2)
- **Несколько вычислений подряд.** После каждой операции программа спрашивает «Хотите выполнить ещё одну операцию? (да/нет)». На `да` расчёт повторяется, на `нет` программа завершается.
- Ошибки больше не завершают программу: после сообщения об ошибке можно продолжить работу.
- При неправильном ответе на вопрос о продолжении вопрос задаётся повторно.
- Числа можно вводить с точкой или запятой.

## Запуск
Нужен Python 3.

```
python calculator.py
```

## Пример работы
```
Введите первое число: 10
Введите операцию: *
Введите второе число: 5
Результат: 50
Хотите выполнить ещё одну операцию? (да/нет): да
Введите первое число: 100
Введите операцию: /
Введите второе число: 0
Ошибка: деление на ноль!
Хотите выполнить ещё одну операцию? (да/нет): нет
Работа программы завершена.
```
