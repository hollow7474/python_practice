# Консольный калькулятор

## Назначение
Простое консольное приложение на Python, которое выполняет арифметические операции над двумя числами.

## Какие задачи решает
- запрашивает у пользователя два числа и операцию;
- выполняет: сложение `+`, вычитание `-`, умножение `*`, деление `/`, целочисленное деление `//`, остаток от деления `%`, возведение в степень `^` (здесь `^` — степень, а не XOR, как в Python);
- обрабатывает ошибки: ввод не числа, неизвестная операция, деление на ноль.

## Запуск
Нужен установленный Python 3.

```
python calculator.py
```

## Как пользоваться
1. Введите первое число.
2. Введите операцию (`+`, `-`, `*`, `/`, `//`, `%`, `^`).
3. Введите второе число.
4. Программа выведет результат.

## Пример работы
```
Введите первое число: 15
Введите операцию: *
Введите второе число: 4
Результат: 60
```
```
Введите первое число: 2
Введите операцию: ^
Введите второе число: 10
Результат: 1024
```
```
Введите первое число: 5
Введите операцию: /
Введите второе число: 0
Ошибка: деление на ноль!
```
